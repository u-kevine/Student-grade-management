# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the
project uses [Semantic Versioning](https://semver.org/).

## [2.0.0] - 2026-10-18

### Added
- **Export Grade Report** (menu 5, US-2): summary, detailed or combined reports saved to
  `reports/<name>.txt`, with file location and size shown after export.
- **Calculate Student GPA** (menu 6, US-3): 4.0-scale conversion per subject, letter grades
  (A, A-, B+ ...), cumulative GPA, class rank and a performance analysis.
- **Bulk Import Grades** (menu 7, US-4): reads CSV files from `imports/`, validates the header,
  validates every row (student, subject, grade), skips bad rows, and writes
  `logs/import_log_<timestamp>.txt`.
- **View Class Statistics** (menu 8, US-5): grade distribution chart, mean, median, mode,
  standard deviation, range, highest/lowest grade, subject and subject-type averages, and
  Regular vs Honors comparison.
- **Search Students** (menu 9, US-6): by exact ID, partial name, average range or type;
  results can be viewed in detail or exported.
- **Custom exceptions** (US-1): `GradeSystemException` base class with recovery hints, plus
  `StudentNotFoundException`, `InvalidGradeException`, `InvalidFileFormatException`,
  `SubjectNotFoundException`, `InvalidInputException`, `NoGradesException`,
  `FileImportException`, `FileExportException` and `InputClosedException`.
- **Input validation** (`InputValidator`) for names, ages, emails, phones, grades, file
  names and search ranges, checked as soon as the user types them.
- **Logging** (`AppLogger`): timestamped log lines in `logs/app.log`; every exception shown
  to the user is also logged.
- **Interfaces** for Interface Segregation and Dependency Inversion: `Searchable`,
  `Exportable`, `Calculable`, `GradingScale`, `CSVParser`, `FileExporter`, `Screen`, `InputCheck`.
- **Sample data** option at start-up (5 students, 25 grades) and sample CSV files in `imports/`.
- **Maven build** (`pom.xml`) with JUnit 5, Mockito and JaCoCo; the build fails below 80% line coverage.
- **185 automated tests**: unit tests, Mockito integration tests and end-to-end menu tests
  (99% line coverage).
- **GitHub Actions CI** (`.github/workflows/ci.yml`) running `mvn verify` on every push and PR.
- Documentation: README, this changelog, testing guide, Git workflow guide, PR template and
  PR descriptions.

### Changed
- Project moved to the standard Maven layout and split into packages
  (`model`, `exception`, `calculator`, `io`, `service`, `ui`, `util`).
- `Student` no longer holds a reference to `GradeManager`; averages are calculated by the
  services (Single Responsibility).
- `StudentManager` and `GradeManager` use `ArrayList` instead of fixed-size arrays, so there is
  no 50-student / 200-grade limit and no "array full" crash.
- Student and grade IDs are generated by the managers instead of static counters, which makes
  the classes testable.
- The `instanceof HonorsStudent` check was replaced by the polymorphic
  `Student.isHonorsEligible()` (Liskov Substitution).
- The big `Main` class was split into one `Screen` class per menu option plus `ConsoleIO`
  for all console input/output; `Main` now only wires the objects together.
- All fixed values moved to `AppConstants` (no magic numbers).
- Printing was removed from model classes (`displayStudentDetails()`, `displaySubjectDetails()`,
  `displayGradeDetails()`); the UI layer does all printing.
- View Grade Report now reuses `ReportGenerator`, so screen and exported reports always match.
- Record Grade lists subject types and subjects from the `SubjectCatalog` instead of hard-coded arrays.

### Removed
- The `Gradable` interface: validation now lives in `InputValidator`, and a `Grade` can no
  longer be created with an invalid value (the constructor throws `InvalidGradeException`).
- The "Confirm grade? (Y/N)" step, to match the new Record Grade flow in the brief.

## [1.0.0] - 2026-10-12

### Added
- Lab 1 console application: Add Student, View Students, Record Grade, View Grade Report, Exit.
- Regular and Honors students, Core and Elective subjects, grade history and averages.
